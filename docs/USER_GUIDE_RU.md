# Litematica Plus LTS: использование и настройки

Руководство для исходников версии **1.0.0-LTS.02**, Minecraft **26.3**, по состоянию на **4 октября 2026 года**. Названия кнопок соответствуют русской локализации проекта. Значения по умолчанию взяты из кода, поэтому настройки ранее установленного профиля могут отличаться.

Поведение описано по реализации. В этой сессии выполнены модульные тесты; Minecraft и многопользовательский сервер не запускались. Технические ограничения и результаты проверки собраны в [анализе проекта](ANALYSIS_RU.md).

## Установка и первый запуск

Litematica Plus LTS — самостоятельный клиентский мод: он читает схемы, показывает их в мире и помогает строить. Litematica и MaLiLib для его работы не требуются. На сервер ставить этот мод не нужно.

| Компонент | Требование этой версии |
|---|---|
| Minecraft | 26.3; метаданные задают `~26.3` |
| Java | 25 или новее; проект компилируется под Java 25 |
| Fabric Loader | Метаданные допускают от 0.19.3; сборка проекта использует 0.19.5 |
| Fabric API | Для целевого профиля — 0.161.0+26.3; мод требует шесть модулей API, перечисленных в метаданных |
| Mod Menu | Необязателен; открывает настройки из списка модов |
| Jade, Stack Calculator, Inventory Profiles Next, Voxy/VoxyMap | Необязательные интеграции |

Порядок установки:

1. Откройте папку нужного игрового профиля. У Modrinth и других лаунчеров она может отличаться от общей `.minecraft`.
2. Установите Fabric для Minecraft 26.3 и Fabric API соответствующей версии.
3. Отключите Litematica, EasyPlaceFix и связанные дополнения, которые заменяете этим модом: их обработчики кликов и отрисовки могут пересекаться. MaLiLib оставьте, если он нужен другим модам. Если Litematica всё же лежит в `mods/`, мод пишет предупреждение в лог, один раз за запуск показывает поверх главного меню экран с кнопками **Открыть папку mods** и **Всё равно продолжить**, а при входе в мир — сообщение в чате.
4. Положите обычный `litematica-plus-lts-1.0.0-LTS.02.jar` в `mods/`. JAR с суффиксом `-sources` предназначен для исходников.
5. Запустите игру, зайдите в мир и нажмите **K**.

Поддерживаются загрузка `.litematic`, `.schem` формата Sponge и `.nbt` структур Minecraft. Сохранение своей постройки создаёт `.litematic`. Старый MCEdit `.schematic` не поддерживается. Одного расширения недостаточно: внутри файла должен находиться поддерживаемый формат NBT.

## Построить по готовой схеме

1. Откройте **K → Схемы → Открыть папку**. Скопируйте туда файл схемы.
2. Вернитесь в игру и нажмите **Обновить**. Папки открываются в браузере схем; поиск фильтрует текущую папку.
3. Выберите файл и нажмите кнопку размещения. Можно активировать строку файла двойным кликом. Размещение создаётся в блочной позиции игрока.
4. Во вкладке **Размещения** выберите нужную копию, задайте координаты, поворот и отражение. Кнопка редактора открывает управление прямо поверх мира.
5. Проверьте высоту основания. Когда положение подходит, включите блокировку размещения.
6. При необходимости откройте **F7 → Слои**, выберите ось Y и режим **Один слой**.
7. Во вкладке **Материалы** посмотрите, что ещё нужно построить и сколько предметов уже есть.
8. Откройте **Настройки → Лёгкая установка** и включите лёгкую установку. По умолчанию она выключена.
9. Уберите палку-инструмент из основной руки. Наведитесь на призрак в пределах обычной дистанции взаимодействия и нажмите правую кнопку. При включённом удержании ведите прицел по нужным блокам, удерживая кнопку.
10. После постройки откройте **Проверка**, исправьте ошибки, затем просмотрите все слои и непрогруженные части.

Можно строить вручную, оставив лёгкую установку выключенной. Средняя кнопка по отсутствующему блоку схемы выбирает нужный предмет, если включена пипетка. В выживании предмет должен быть в инвентаре; в творческом режиме мод может создать предмет в хотбаре.

**Схема** — файл с постройкой. **Размещение** — её копия в конкретных координатах мира. Один файл можно разместить несколько раз. Переименование или удаление размещения не меняет и не удаляет файл схемы.

## Меню и управление

| Вкладка | Для чего нужна |
|---|---|
| Быстрый доступ | Состояние выбранного размещения и основные переключатели |
| Схемы | Браузер файлов, поиск, сведения и превью |
| Размещения | Выбор копии, координаты, поворот, отражение, блокировка, подрегионы |
| Слои | Срез по X/Y/Z и дополнительные границы X/Z |
| Новая схема | Боксы выделения и сохранение постройки |
| Материалы | Потребность, запасы, сортировка и экспорт |
| Замены | Замена блоков схемы другими блоками для выбранного размещения |
| Проверка | Ошибки блоков и подсветка выбранной позиции |
| Настройки | Отображение, инструменты, лёгкая установка, клавиши и производительность |

Главное меню помнит последнюю открытую вкладку и не ставит одиночную игру на паузу. Настройки разбиты на страницы: если параметр не виден, используйте `<` и `>` внизу. В превью схемы левое перетаскивание вращает изображение, правое сдвигает, колесо меняет масштаб.

### Палка-инструмент

По умолчанию инструментом служит `minecraft:stick`. Он работает в основной руке, когда включён параметр **Инструмент активен**, и не работает в наблюдателе.

| Режим | Левая кнопка | Правая кнопка |
|---|---|---|
| Область | Угол 1 выбранного бокса | Угол 2 |
| Перемещение | Перенести начало выбранного размещения к цели | Повернуть на 90° |
| Вставка | Запросить, затем подтвердить вставку | Снять подтверждение и остановить операцию |
| Удаление | Запросить, затем подтвердить удаление выделенной области | Снять подтверждение и остановить операцию |

Дополнительный ввод с инструментом:

| Ввод | Действие |
|---|---|
| Ctrl + колесо | Сменить режим инструмента |
| Средняя кнопка | Следующий режим; с Shift — предыдущий |
| Alt + клик | Использовать блочную позицию игрока вместо цели |
| Alt + колесо | Сдвинуть выделение или размещение по направлению взгляда |
| Shift + Alt + колесо в режиме области/удаления | Сдвинуть первый угол вместо всего бокса |

В обычном выделении углы ставятся на сам блок под прицелом. При перемещении начало схемы ставится в соседнюю клетку со стороны нажатой грани. Если цели нет, используется позиция игрока. Инструмент может выбирать цель до 160 блоков; это не увеличивает дистанцию лёгкой установки.

## Точное размещение

Выберите размещение и откройте редактор. Это прозрачный экран с панелью справа; он не ставит блоки автоматически.

| Ввод в редакторе | Результат |
|---|---|
| Левое перетаскивание вне панели | Перемещение схемы по горизонтальной плоскости |
| Клик по числу X/Y/Z, ввод, Enter | Установить координату |
| Ctrl+V | Вставить координаты из буфера; поддерживается набор `x y z` |
| Стрелки | Сдвиг по горизонтали относительно направления редактора |
| PgUp / PgDn | Сдвиг вверх / вниз |
| Shift со стрелками/PgUp/PgDn | Сдвиг на десять выбранных шагов |
| Кнопка шага | Цикл 1, 5, 16, 64 блока |
| Колесо вне панели в обычном виде | Изменить высоту размещения |
| R | Поворот на 90° |
| M | Следующее отражение |
| T | Переключить вид сверху |
| Колесо в виде сверху | Изменить масштаб |
| Правое перетаскивание в виде сверху | Переместить камеру |
| Esc | Закрыть редактор |

Блокировка запрещает движение, поворот, отражение и переключение подрегионов. Скрытие размещения выключает его участие в показе и построении. **Блокировка не является защитой мира от вставки**: это фиксация положения схемы.

Поворот и отражение применяются вокруг начала размещения, поэтому его X/Y/Z не обязательно совпадают с минимальным углом видимой постройки. Во вкладке **Размещения** можно отключить отдельные подрегионы; независимо перемещать подрегионы эта версия не умеет.

Вид сверху переносит камеру, но не игрока и не прогрузку чанков. Чтобы видеть дальний рельеф, нужно прогрузить его обычным способом либо использовать соответствующие возможности Voxy/VoxyMap.

## Слои и границы

Нажмите **F7**. Ось Y даёт горизонтальные этажи; X и Z — вертикальные срезы.

| Режим | Что показывается |
|---|---|
| Все слои | Все координаты выбранной оси |
| Один слой | Только указанная координата |
| Этот и ниже | Координаты не больше указанной |
| Этот и выше | Координаты не меньше указанной |
| Диапазон | От минимума до максимума, включительно |

**Слой здесь** берёт координату игрока по выбранной оси. Для диапазона сохраняет его ширину. Смена оси берёт новую координату игрока и задаёт диапазон вокруг неё.

Границы X/Z дополнительно обрезают схему. Можно включить только X, только Z или обе оси. Кнопка подгонки к размещению устанавливает его границы; **Сброс** убирает обрезку X/Z, сохраняя режим слоя.

Эти ограничения общие для активных схем в текущей сессии. Лёгкая установка и пипетка учитывают текущий срез. Если включено **Считать только видимую часть**, прогресс, счётчики и материалы относятся к срезу и границам. «Видимая часть» здесь означает координатный фильтр, а не только то, что попало в кадр.

**Вставка не ограничивается выбранным слоем или границами X/Z.** Для вставки части постройки отключайте ненужные подрегионы либо используйте отдельную схему нужной части.

## Лёгкая установка

Она выбирает материал, подбирает точку клика и направление, отправляет обычные действия взаимодействия игре и при необходимости доводит состояние блока дополнительными кликами. Она не обходит права сервера и не строит всю схему по одному нажатию.

Условия работы:

- Включены **Показывать схемы** и **Лёгкая установка**.
- Размещение включено, загружено и нужная клетка входит в текущие слои/границы.
- Игрок может строить, не находится в наблюдателе, а цель доступна для взаимодействия.
- Нет открытого экрана; в основной руке нет активной палки-инструмента.
- В выживании нужный предмет доступен в основных 36 слотах инвентаря. Предметы внутри шалкера сначала нужно достать.
- Блок имеет необходимую опору и место; второй блок двери/кровати создаётся обычным действием игры.

Материал выбирается автоматически из хотбара или переставляется из основного инвентаря в текущий слот хотбара. Предметы с изменёнными компонентами, например переименованные, по умолчанию не используются для обычной установки.

### Темп и ориентация

| Темп | Базовая задержка |
|---|---|
| Баланс / `BALANCED` | 2 тика |
| Осторожно / `SAFE` | 4 тика |
| Быстро / `FAST` | 1 тик |
| Свой / `CUSTOM` | Значение «Своя задержка», 0–20 тиков |

При обычных 20 тиках в секунду 2 тика — около 0,1 с. Это базовая пауза, а не гарантированная скорость: дополнительно работают ожидание поворота, отклик сервера и повторные клики. Случайный лишний тик добавляет 0 или 1 тик.

**Только точная ориентация** пропускает блок, если подходящий план клика не найден. Отключение позволяет ставить приблизительно и затем исправлять ошибки. **Поворот для сервера** отправляет нужный взгляд без поворота видимой камеры. Настройка упреждения задаёт 0–3 тика; для некоторых направленных блоков код дополнительно выдерживает минимум 2 тика.

На сервере, который отклоняет установки, попробуйте темп **Осторожно**, отключите клики по скрытым граням/воздуху и подойдите ближе. Профиль «Осторожно» не гарантирует совместимость с античитом; реальный сервер в этом анализе не проверялся.

### Дополнительные состояния

При включённом доведении состояния предусмотрены дополнительные действия для повторителей, компараторов, рычагов, датчиков дневного света, открываемых вручную дверей/люков/калиток, точек и крестов редстоуна, двойных плит, свечей, слоёв снега и ряда других наращиваемых блоков. Есть настройка нот, заполнение горшка, свеча на торте, вставка ока в рамку портала и зарядка якоря светокамнем.

Эти действия требуют обычных предметов и условий игры. Мод не может произвольно установить любое свойство: например, состояние двери, удерживаемой сигналом редстоуна, определяется миром.

После установки таблички мод отправляет простой текст лицевой стороны из схемы. Полное форматирование, цвет, свечение и обратная сторона не воспроизводятся этим путём. Для сборщика предусмотрено отключение слотов через его интерфейс. Произвольное содержимое сундуков лёгкая установка не переносит.

### Сущности

Поддерживается помощь для обычных и светящихся рамок, картин и стоек для брони. Наведитесь на маркер и используйте правую кнопку. Мод может заполнить рамку предметом, повернуть предмет и надеть броню на стойку. Запасы на это **не входят в список материалов**.

Это ограниченная поддержка сущностей, а не перенос всего entity NBT: не обещаются все позы и свойства стоек, любые мобы или произвольные сущности. При сохранении постройки на внешнем сервере сущности не захватываются; в одиночной игре они читаются со встроенного сервера.

### Разрушение и замены

**Защита при раскопках** действует совместно с лёгкой установкой и общим отображением. Она может запрещать ломание вне активной схемы и уже совпадающих блоков. Это помощник клиентского ввода, а не серверная защита территории.

**Ломать неверные блоки** позволяет лёгкой установке выкопать мешающий блок и повторить установку. Исключаются жидкости, неразрушаемые блоки и блоки, чья блочная сущность реализует контейнер. Режим не удаляет все «лишние» блоки там, где схема ожидает воздух: такие места убираются вручную.

**Замена вариантов земли** ограничена землёй, дёрном, грубой землёй и тропинкой, причём оба варианта должны входить в этот набор. Она не заменяет камень на землю. При включённом **Земля и дёрн взаимозаменяемы** землю и дёрн друг на друга она не меняет.

**Не портить блоки схемы инструментами** отменяет правый клик лопатой, мотыгой или топором по блоку внутри размещения, если результат (тропинка, грядка, обтёсанное бревно) не совпадает со схемой. Проверка идёт без учёта слоя и срабатывает, только когда клик не забрала лёгкая установка.

**Защита слотов** (Настройки → Инструменты) — отмеченные слоты хотбара 1–9. Лёгкая установка, пипетка и автосмена инструмента только выбирают такие слоты, но не кладут в них другие предметы.

**Замена материалов** используется, когда нужного предмета нет. Предусмотрены семейства стен, калиток, люков и коралловых вееров, а также пользовательский список блоков. Возьмите блок в руку и нажмите **Добавить из руки**. Список общий, до 256 предметов; это не таблица «блок A заменять только на B».

Этот список не изменяет исходную схему. Проверка по-прежнему сравнивает мир с исходными блоками и может показывать заменённый материал как ошибку. Очистка списка удаляет правила для будущих действий, уже поставленные блоки остаются.

### Замены блоков

Вкладка **Замены** работает иначе: для выбранного размещения любой блок схемы, кроме блоков с содержимым (сундуки, таблички), заменяется другим блоком; похожие варианты предлагаются первыми. Замена применяется при сборке объёма размещения, поэтому призраки, проверка, материалы, лёгкая установка и вставка видят уже заменённый блок. Файл схемы не меняется, замены хранятся у размещения в файле сессий. Опция **Применять замены блоков** (`materialSwap`) выключает их, не удаляя.

**Засчитывать похожие блоки** (`looseBlocks`) — отдельное правило сверки: блок той же группы (одинаковые свойства, форма коллизии, непрозрачность, трение, сыпучесть, свет) считается верным, и ломание неверных блоков его не трогает. Редстоун, рельсы и блоки с блочной сущностью сравниваются строго.

## Материалы и контейнеры

Выберите размещение и откройте **Материалы**.

| Показатель | Значение |
|---|---|
| Всего | Предметы для выбранного объёма схемы |
| Не хватает | Предметы для частей, которые ещё не признаны совпадающими |
| У вас | Предметы в инвентаре, включая распознанное содержимое переносимых контейнеров |
| Ещё собрать / дефицит | `max(0, Не хватает − У вас)` |

Пример: всего 1 000 камня, 600 уже совпадают, ещё 150 в инвентаре. «Не хватает» — 400, собрать нужно ещё 250. Если блок есть, но его состояние неверное, он ещё не считается готовым и может сохранять потребность в материале.

Подсчёт учитывает две плиты для двойной плиты, одну нижнюю часть двери и одну часть кровати, количество свечей/слоёв/подобных предметов, цветок с горшком, свечу с тортом. Для воды и лавы учитываются источники. Это не полный список всех расходников: сущности и некоторые предметы для доведения состояний, например око портала, не добавляются отдельными строками.

Содержимое эндер-сундука прибавляется к «У вас» в списке материалов и на инфопанели, если включено **Учитывать эндер-сундук в материалах** и после входа эндер-сундук был открыт хотя бы раз. Помощник у контейнеров считает без него.

Пока схемы скрыты или выбранное размещение выключено, при включённом **Скрытая схема о себе не сообщает** инфопанель, помощник у контейнеров и строки в подсказках предметов ничего о ней не показывают.

Сортировки: по оставшемуся количеству, общему количеству, названию и дефициту для сбора. **Скрывать готовые** скрывает строки без оставшейся потребности. В узком окне разбивка на стаки может не показываться.

### Помощник в хранилищах

При включённом помощнике и выбранном размещении откройте сундук, бочку, эндер-сундук, шалкер, воронку, раздатчик либо поддерживаемый инвентарь ездового животного.

| Подсветка | Значение |
|---|---|
| Зелёная | Нужный предмет россыпью |
| Жёлтая | Переносимый контейнер с нужными предметами внутри |
| Голубая | Слоты, соответствующие строке под курсором |

Действия боковой панели:

- **Взять нужное** — взять недостающие запасы. Сначала используются свободные предметы, затем полезные шалкеры целиком.
- Левый клик по строке — взять нужное количество этого материала.
- Shift + левый клик — взять доступные свободные предметы этого типа; этот путь не распаковывает шалкеры.
- Правый клик — открыть расчёт количества через Stack Calculator, если интеграция доступна.
- **Сложить лишнее** — вернуть избыточные материалы схемы. Посторонние предметы не собираются общей уборкой инвентаря.
- Назначенная клавиша **Взять материалы** запускает сбор из открытого поддерживаемого хранилища.

Перед переносом положите предмет с курсора. Пока перенос идёт, дождитесь результата. Закрытие контейнера останавливает дальнейшие действия.

**Брать ровно сколько нужно** включает разделение стаков. Это цель алгоритма; при слишком длинном плане он может перейти к переносу целого стака. Перенос не распаковывает шалкеры и не гарантирует точное количество при вмешательстве сервера.

При складывании лишнего сохраняются текущий предмет в основной руке и закреплённые слоты Inventory Profiles Next, если его API доступен. Защита закреплённых слотов в этом помощнике не означает, что все способы выбора предмета в лёгкой установке соблюдают блокировку IPN.

### Экспорт

Нажмите **Материалы → Экспорт** и выберите XLSX, CSV, MD, JSON или буфер обмена.

Файлы сохраняются в `litematica-plus/materials/` внутри игрового профиля. Сообщение в чате содержит ссылку на файл и папку. XLSX содержит сводку, потребность в сборе и полный перечень; форматирование готового файла формируется самим модом.

**Буфер обмена копирует текущие показанные строки**, с учётом скрытия готовых. **Файловый экспорт строится по всему вычисленному списку**, включая строки, скрытые переключателем. Слои/границы влияют на вычисленный объём, если включён соответствующий подсчёт.

## Проверка постройки

Во вкладке **Проверка** отображается до 200 результатов, выбранных из ближайших секций. Для огромной постройки перемещайтесь по области: это ограниченный список, а не полный экспорт ошибок.

| Категория | Цвет | Значение |
|---|---|---|
| Не хватает блока | Голубой | Схема требует блок, в мире воздух |
| Лишний блок | Розовый | Схема ожидает воздух, в мире блок |
| Не тот блок | Красный | Тип блока отличается |
| Неверное состояние | Оранжевый | Блок тот же, но отличаются свойства |
| Верно | Зелёный в обозначениях | Блок совпадает по действующим правилам |
| Неизвестно | Серо-голубой в обозначениях | Нет достаточных данных мира |

Переключатели категорий управляют их показом; они не исправляют мир. Выбор строки выделяет позицию рамкой. **Убрать выделение** снимает рамку.

По умолчанию игнорируются изменчивые свойства вроде возраста растений и текущей мощности редстоуна. При этом ориентация, задержка повторителя, режим компаратора, нота и другие конструктивные свойства продолжают иметь значение. Для строгой проверки выключите **Игнорировать изменчивые свойства**.

На внешнем сервере **Скрытые блоки считать верными** может признать другой блок совпадающим, если он закрыт с шести сторон. Это компромисс для антирентгена, который подменяет данные клиенту. В одиночной игре правило отключается автоматически. Для точной инспекции скрытого объёма выключите его и обеспечьте достоверные данные мира.

Непрогруженные участки могут использовать ранее полученные результаты или кэш Voxy/VoxyMap. Кэш отражает сохранённое состояние, поэтому его данные могли устареть. Отсутствие строк ошибок не означает, что все чанки проверены.

**100% готовности — доля совпавших ненулевых блоков в выбранном объёме.** Она не гарантирует отсутствие лишних блоков в ожидаемом воздухе, совпадение содержимого контейнеров или установку всех сущностей. Для финальной проверки включите все категории, режим всех слоёв, сбросьте границы и просмотрите неизвестные участки.

## Сохранить свою постройку

1. Откройте **Новая схема** и добавьте бокс.
2. Возьмите палку. Переключите режим на **Область**.
3. Левой и правой кнопкой задайте противоположные углы. Обе граничные клетки входят в выделение.
4. При необходимости поправьте координаты в меню. Кнопка **Здесь** берёт позицию игрока.
5. Добавьте другие боксы для отдельных частей и дайте им понятные названия.
6. Убедитесь, что все нужные чанки прогружены. Часть без данных записывается пустой; после сохранения мод предупреждает о пропущенных чанках.
7. Введите имя файла и сохраните. Если файл уже есть, потребуется второй клик для замены.
8. Откройте сохранённую схему и проверьте результат загрузкой/размещением.

Автор берётся из настройки **Автор**, а если она пуста — из имени игрока. Сохранение создаёт `.litematic` в корневой папке схем. Недопустимые символы имени заменяются; имя нельзя использовать для выбора произвольного пути.

Лимит суммарного объёма боксов: **16 777 216 клеток** на внешнем сервере и **134 217 728** в одиночной игре. Воздух входит в объём. Пересечения боксов также входят в сумму. Это верхняя граница допуска, а не обещание быстрой обработки.

В одиночной игре данные считываются со встроенного сервера, включая сохраняемые сущности. На внешнем сервере доступно только то, что известно клиенту; полного содержимого удалённых контейнеров и сущностей ожидать нельзя. Захват большого выделения может вызвать паузу, поскольку создание снимка не разбито на маленькие шаги.

## Вставка и удаление

Оба действия меняют реальные блоки. Они предназначены для творческого режима. В этой версии нет собственного журнала отмены: остановка прекращает продолжение, но не возвращает изменённые блоки. Перед большой операцией сохраните копию мира.

### Вставка

Выберите размещение. В редакторе нажмите **Вставить**, затем подтвердите вторым нажатием. Альтернативный путь — палка в режиме **Вставка** и два отдельных левых клика. Подтверждение действует 80 клиентских тиков, примерно 4 с при 20 TPS; между кликами инструмента выдерживается короткая пауза.

В одиночной игре запись идёт напрямую через встроенный сервер. Проверяется творческий режим; видимость команды `/setblock` для этого пути не требуется. На внешнем сервере используется отправка команд, и должна быть доступна команда `/setblock`; для удаления — `/fill`. Сервер всё равно может отклонить действие из-за прав или защиты территории.

| Режим замены | Что меняется |
|---|---|
| Всё / `ALL` | Мир приводится к блокам схемы, включая очистку там, где схема содержит воздух |
| Только блоки / `NON_AIR_ONLY` | Ставятся ненулевые блоки схемы; её воздух не очищает мир |
| Только в воздух / `INTO_AIR_ONLY` | Блоки схемы ставятся только в клетки с воздухом |

Вставляется весь подготовленный объём размещения с включёнными подрегионами. Слои и границы X/Z не ограничивают операцию. Параметр блокировки положения также не является запретом вставки.

Непрогруженные клиентом секции пропускаются. Даже на встроенном сервере перед вставкой нужно прогрузить целевую область. Не поддерживается автоматическая вставка сущностей.

**Вставлять содержимое** переносит данные блочных сущностей только при прямой вставке в одиночной игре. Командная вставка на внешнем сервере их не отправляет. Слишком длинные команды, более 255 символов, пропускаются.

**Команд вставки за тик** действует на командный путь. Для игрока без признака полномочий администратора мод снижает темп примерно до одной команды в секунду, даже если команда предоставлена серверным плагином. Счётчик отправленных изменений не является подтверждением применения сервером: результат проверяется по миру после завершения.

### Удаление

Удаление использует **все полностью заданные боксы выделения**, а не выбранное размещение. Проверьте их во вкладке **Новая схема**, затем возьмите инструмент и переключите его в режим **Удаление**. Два левых клика запрашивают и подтверждают очистку; правая кнопка останавливает.

Лимит — **67 108 864 клетки** по сумме боксов. Область разбивается на части до 32×32×32. Части с непрогруженными чанками пропускаются. Командное удаление отправляет `/fill ... minecraft:air strict` с отдельным ограничением темпа; настройка команд вставки не задаёт его скорость.

## Полный справочник настроек

`Вкл.` соответствует JSON `true`, `Выкл.` — `false`. Числа и строковые enum в JSON записываются без русских переводов. Настройки применяются кнопкой сохранения; при уходе с вкладки корректные несохранённые изменения также сохраняются. Кнопка возврата изменений относится к ещё не применённой рабочей копии и не отменяет назначения клавиш.

### Производительность

| Название / ключ JSON | По умолчанию | Действие и диапазон |
|---|---|---|
| Рабочие потоки / `workerThreads` | 0 | 0–16; 0 = автоматически `max(1, min(6, число логических CPU / 2))` |
| Загрузок секций за кадр / `meshUploadsPerFrame` | 24 | 1–256; верхняя граница обработки готовых секций, дополнительно действует бюджет времени загрузки |

Бюджеты контролируют очередь и время работы, но не являются строгим ограничителем каждой отдельной операции. Максимум потоков не обязательно даёт лучший результат: он увеличивает конкуренцию за CPU и расход памяти.

## Практические наборы настроек

Это отправные настройки по смыслу параметров, а не измеренные оптимальные профили.

| Задача | Что выставить |
|---|---|
| Только голограмма и ручная стройка | Лёгкая установка выкл.; призраки и подсветка вкл.; пипетка вкл. |
| Обычная стройка в выживании | Лёгкая установка вкл.; Баланс; точная ориентация, доведение и взаимодействие вкл.; авторазрушение сначала выкл. |
| Сервер отклоняет клики | Осторожно; клики по воздуху/скрытым граням выкл.; диагностика вкл.; обычная дистанция и реальные опоры |
| Строительство одного этажа | Ось Y, Один слой; Считать только видимую часть вкл. |
| Проверка всего здания | Все слои; сброс границ; все категории ошибок вкл.; для строгого результата игнорирование изменчивых свойств и доверие скрытым блокам выкл. |
| Большая схема вызывает рывки | Сначала снизить дальность, отключить детальные превью/спецблоки; оставить потоки в авто; затем уменьшать загрузки секций и бюджет снимков, принимая более долгую обработку |
| Нужно сохранить существующий рельеф при вставке | `NON_AIR_ONLY` не очищает по воздуху схемы; `INTO_AIR_ONLY` также не заменяет занятые клетки |

Для больших схем увеличивайте только один параметр за раз и смотрите диагностику. Большая дальность схемы не исправляет отсутствие прогруженных чанков. В режиме карты VoxyMap и в виде сверху мод может увеличивать эффективную дальность автоматически.

## Файлы и восстановление

Все пути ниже относятся к папке **текущего игрового профиля**.

| Путь | Что хранится |
|---|---|
| `config/litematicaplus.json` | Основные настройки |
| `config/litematicaplus.json.bak` | Предыдущая резервная копия настроек |
| `config/litematica-plus-session.json` | Размещения, выбранная копия, боксы, слои, границы, режим инструмента по миру/серверу и измерению |
| `config/litematica-plus-session.json.bak` | Резервная копия сессий |
| `config/litematica-plus-substitutes.json` | Список допустимых замен |
| `config/litematica-plus-substitutes.json.bak` | Его резервная копия |
| `config/litematicaplus/previews/` | Восстанавливаемый PNG-кэш превью |
| `schematics/` | Схемы при стандартном пути |
| `litematica-plus/materials/` | Экспорт материалов |
| `options.txt` | Назначения клавиш Minecraft и мода |

Настройки глобальные для профиля; размещения разделяются по адресу сервера/имени каталога одиночного мира и измерению. После повторного входа опасные режимы инструмента «Вставка» и «Удаление» заменяются режимом области.

Сохранение JSON использует временный файл, замену основного и резервную копию. Если основной файл повреждён, мод пытается читать `.bak`. Файл сессий более новой версии открывается только для чтения. Основной конфиг такой защиты не имеет: неизвестные параметры более нового формата могут потеряться при сохранении старой версией мода.

Для ручного редактирования:

1. Закройте Minecraft, чтобы фоновые записи не перезаписали изменения.
2. Скопируйте основной JSON и `.bak` в отдельную резервную папку.
3. Измените поля, сохраняя корректный JSON. Для Windows-пути удобно использовать `/`.
4. Запустите игру и проверьте параметр в меню.

Для полного сброса основных настроек после резервного копирования переименуйте **и основной конфиг, и его `.bak`**: иначе мод восстановит старые настройки из копии. Сессии и схемы сбрасывать для этого не требуется.

Схемы не встроены в файл сессий. Если файл перемещён или удалён, размещение не загрузится; верните файл по прежнему пути или создайте размещение заново. Замена существующей `.litematic` при сохранении не создаёт штатную `.bak` схемы, поэтому её копию сохраняйте отдельно.

## Решение проблем

| Симптом | Проверка и действие |
|---|---|
| K не открывает меню | Проверить установку именно в активный профиль, назначение в управлении и конфликт клавиш; открыть через Mod Menu |
| Файл не появляется | Нужная папка профиля, поддержанное расширение, текущая подпапка, пустой поиск, Обновить; `.schematic` не поддерживается |
| Ошибка загрузки | Сообщение во вкладке размещений и `logs/latest.log`; файл может быть повреждён или содержать неподдержанное NBT |
| Схема загружена, но невидима | Общий показ, активность размещения, координаты/измерение, слои/границы, дальность, наличие недостающих блоков |
| Дальняя часть невидима | Прогрузить чанки; «Призраки только в прогруженных чанках» включено по умолчанию; кэш мира требует Voxy и VoxyMap |
| Призрак виден поверх дальнего рельефа | Вернуть ограничение по прогруженным чанкам; проверить глубину Voxy/совместимость рендера |
| Правый клик выделяет угол | В руке палка-инструмент; сменить предмет или выключить инструмент |
| Правый клик ничего не строит | Включить лёгкую установку и общий показ; закрыть меню; приблизиться; проверить слой, предмет, опору и возможность точного клика |
| В инвентаре есть материал, но отказ «нет предмета» | Он может лежать внутри шалкера, во второй руке или иметь изменённые компоненты; достать обычный предмет в основные слоты |
| Сундук открывается вместо установки | Включено обычное взаимодействие; использовать Shift+клик либо изменить его настройку |
| Нельзя ставить блок вручную рядом со схемой | «Без лишних блоков» действует ещё на 2 блока вокруг; отключить его, лёгкую установку либо проверить отдельную «Защиту от ошибок» |
| Нельзя ломать | Проверить защиту раскопок и её правила; отключение лёгкой установки снимает эту защиту |
| Нет панели материалов | Выбрано размещение, включены помощник и панель, открыто поддерживаемое хранилище; после изменения настройки переоткрыть контейнер |
| Перенос остановился | Предмет на курсоре, полный инвентарь/контейнер, вмешательство сервера; освободить место и повторить |
| Материал взят с запасом | Перенесён шалкер целиком, отключён точный режим или сработал переход к переносу целого стака |
| Материалы/процент изменились при смене слоя | Включён подсчёт только видимой части; для общего результата вернуть все слои и сбросить границы |
| 100%, но есть ошибки | Процент относится к ненулевым блокам; лишние блоки, сущности и данные контейнеров проверяются отдельно |
| Блок неправильной стороной | Точная ориентация и поворот для сервера, упреждение, реальные опоры; возможен отказ/переписывание состояния сервером |
| Наблюдатель не ставится | Включено ожидание наблюдаемого блока; поставить его первым |
| Не работает вставка | Творческий режим; на сервере доступная команда и права; нет другой операции; целевые чанки прогружены |
| Слои не ограничили вставку | Так устроена эта версия; остановить дальнейшую запись, результат уже изменённых блоков восстанавливать из копии мира |
| После ошибки рендера схема пропала | В журнале искать `Schematic rendering failed` или `Schematic block entity rendering failed`; перезапустить клиент и проверить сочетание модов/шейдеров |
| После входа размещение не восстановилось | Тот же адрес сервера/каталог мира и измерение, сохранённый JSON, исходный файл схемы доступен; проверить режим только чтения сессий |

Исходники поддерживают интеграции с Sodium/Iris через точки отрисовки, Jade, Stack Calculator, IPN и VoxyMap, однако конкретная комбинация версий требует проверки в игре. При отсутствии необязательного API интеграции обычно отключаются. Показ на карте VoxyMap дополнительно зависит от её переключателя схем; подсветка ошибок на карте подавляется.
