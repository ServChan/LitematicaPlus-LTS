## Быстрый старт

### Построить по готовой схеме — за 5 минут

1. Положите `litematica-plus-lts-1.0.5.jar` в папку `mods` вместе с Fabric API. Litematica, MaLiLib и EasyPlaceFix уберите: мод заменяет их.
2. Запустите игру, зайдите в мир и нажмите **H** — откроется меню мода.
3. Вкладка **Схемы** → кнопка **Папка**. Скопируйте в открывшуюся папку файл `.litematic`, `.schem`, `.schematic`, `.nbt` или `.bp`, затем нажмите **Обновить**.
4. Выберите файл и нажмите **Разместить здесь**. Схема появится голограммой у ваших ног, и откроется редактор размещения.
5. В редакторе подвиньте схему: тяните левой кнопкой мыши, колесо меняет высоту, **R** поворачивает, **M** отражает, **T** показывает вид сверху. Точные координаты можно вписать в поля X/Y/Z. Закройте редактор кнопкой **Готово** или **Esc**.
6. Снова **H** → **Настройки** → категория **Установка** → включите **Лёгкая установка**.
7. Уберите из основной руки палку (это инструмент мода). Наведитесь на полупрозрачный блок-призрак и нажмите правую кнопку мыши: мод возьмёт нужный блок из инвентаря и поставит его с правильным поворотом. Держите кнопку и ведите прицел, чтобы ставить подряд.
8. Чего не хватает, смотрите во вкладке **Материалы**; что поставлено неправильно — во вкладке **Проверка** и по цветной подсветке в мире.

Строить можно и вручную, без лёгкой установки: призраки показывают, что куда ставить, а средняя кнопка мыши по призраку берёт нужный блок в руку.

### Сохранить свою постройку — за 2 минуты

1. Возьмите в руку палку.
2. **Ctrl + колесо мыши** — выберите режим **Область** (название режима видно над хотбаром).
3. Левой кнопкой отметьте первый угол постройки, правой — противоположный.
4. **H** → вкладка **Новая схема**, впишите имя файла и нажмите **Сохранить**. Схема появится во вкладке **Схемы**.

### Что запомнить сразу

| Клавиша | Действие |
|---|---|
| `H` | Меню мода |
| `F7` | Слои и границы X/Z |
| ПКМ по призраку | Лёгкая установка (если включена) |
| СКМ по призраку | Взять нужный блок в руку |
| Палка + `Ctrl` + колесо | Сменить режим инструмента |
| `Ctrl+F` в настройках | Поиск по настройкам |

Остальные клавиши мода по умолчанию не назначены — назначьте нужные в **Настройки → Клавиши**.

## Установка

| Компонент | Требование |
|---|---|
| Minecraft | 26.3 (метаданные мода: `~26.3`) |
| Java | 25 или новее |
| Fabric Loader | 0.19.3 или новее (мод собран на 0.19.5) |
| Fabric API | 0.161.0+26.3 |
| Mod Menu | Необязателен: открывает настройки мода из списка модов |
| Sodium, Iris, Voxy, VoxyMap, Jade, Stack Calculator, Inventory Profiles Next, Axiom | Необязательные интеграции, см. [Аддоны](#аддоны-и-совместимость) |

Мод только клиентский: на сервер его ставить не нужно.

1. Откройте папку нужного игрового профиля. У Modrinth App и других лаунчеров у каждого профиля своя папка, это не обязательно `.minecraft`.
2. Установите Fabric Loader для 26.3 и Fabric API.
3. Уберите из `mods` Litematica, MaLiLib и EasyPlaceFix: их функции уже внутри мода. MaLiLib оставьте, только если он нужен другим модам. Если Litematica всё-таки окажется рядом, мод при запуске покажет поверх главного меню предупреждение с кнопками **Открыть папку mods** и **Всё равно продолжить**, а при входе в мир напишет об этом в чат: вместе моды перехватывают одни и те же клики и рисуют схемы дважды.
4. Положите в `mods` **один** из двух файлов:
   - `litematica-plus-lts-1.0.5.jar` — обычная версия;
   - `litematica-plus-lts-1.0.5-printer.jar` — та же версия плюс принтер (см. [Версия с принтером](#версия-с-принтером)). Многие серверы запрещают принтеры, поэтому в обычной версии его кода нет.
5. Запустите игру и нажмите **H** в мире.

Папка `schematics/` общая с Litematica: если вы ею пользовались, все схемы уже на месте.

### Сборка из исходников

```powershell
.\gradlew.bat clean build
```

Готовые файлы — `build/libs/litematica-plus-lts-1.0.5.jar` и `build/libs/litematica-plus-lts-1.0.5-printer.jar`.

## Основные понятия

- **Схема** — файл с постройкой (`.litematic` и другие форматы).
- **Размещение** — схема, поставленная в мир в определённых координатах. Один файл можно разместить сколько угодно раз. Удаление или переименование размещения не трогает файл.
- **Призрак** — полупрозрачный блок схемы там, где в мире его ещё нет.
- **Подсветка ошибок** — цветные рамки на неверных, лишних и недостающих блоках.
- **Подрегион** — часть схемы (в `.litematic` их может быть несколько). Подрегионы можно скрывать, сдвигать и поворачивать по отдельности.
- **Слой** — срез схемы по оси X, Y или Z. Пока задан слой, мод показывает и помогает строить только его.
- **Инструмент** — предмет (по умолчанию палка), которым выделяют области, двигают размещения, вставляют и удаляют.
- **Зона** — часть размещения, которую берёт себе один игрок при совместной стройке.

## Меню мода

Меню открывается клавишей **H** или из Mod Menu. Оно запоминает последнюю вкладку и не ставит одиночную игру на паузу.

| Вкладка | Для чего |
|---|---|
| Быстрый доступ | Сводка по выбранному размещению: прогресс, ошибки, быстрые переключатели, текущий слой |
| Схемы | Библиотека файлов: поиск, сортировка, 3D-превью, размещение, экспорт, удаление |
| Размещения | Схемы в мире: координаты, поворот, отражение, блокировка, подрегионы, сетка копий, вставка |
| Зоны | Деление размещения на участки для командной стройки |
| Сервер | Общие схемы сервера через Syncmatica |
| Слои | Срез по слоям и границы X/Z (`F7`) |
| Новая схема | Выделение области и сохранение её в файл |
| Материалы | Сколько каких блоков нужно, сколько есть, где лежит недостающее; экспорт |
| Замены | Замена блоков схемы другими без изменения файла |
| Проверка | Список ошибок рядом с вами; щелчок подсвечивает место в мире |
| Настройки | Все параметры по категориям, поиск, клавиши |
| Аддоны | Состояние интеграций с другими модами и журнал проблем |

Наведите курсор на кнопку или настройку — появится подсказка, что она делает.

## Управление

### Клавиши мода

Клавиши назначаются в **Настройки → Клавиши** или в обычном меню Minecraft «Управление», категория Litematica Plus.

| Действие | По умолчанию |
|---|---|
| Открыть Litematica Plus | `H` |
| Открыть слои и границы X/Z | `F7` |
| Править размещение в мире (редактор) | не назначена |
| Показать/скрыть схемы | не назначена |
| Переключить лёгкую установку | не назначена |
| Включить/выключить инструмент | не назначена |
| Следующий режим инструмента | не назначена |
| Следующий режим слоёв | не назначена |
| Слой выше / Слой ниже | не назначены |
| Включить/выключить границы X/Z | не назначена |
| Открыть список материалов | не назначена |
| Скрыть призрак блока под прицелом | не назначена |
| Показать все скрытые блоки | не назначена |
| Переключить установку удержанием | не назначена |
| Переключить защиту при раскопках | не назначена |
| Переключить автосмену инструмента | не назначена |
| Переключить ломание неверных блоков | не назначена |
| Переключить замену материалов | не назначена |
| Вкл/выкл призраки только у ошибок | не назначена |
| Вкл/выкл подсветку того, что можно поставить | не назначена |
| Взять материалы из открытого контейнера | не назначена |
| Вкл/выкл принтер (только версия с принтером) | не назначена |

Как назначить клавишу:

1. Щёлкните строку действия — появится «нажмите клавишу...».
2. Нажмите клавишу или кнопку мыши (кроме левой). Чтобы назначить сочетание, держите `Ctrl`, `Shift` или `Alt`, например `Ctrl + K`. Чтобы назначить один `Alt`, нажмите и отпустите его.
3. `Esc` снимает назначение, левый клик отменяет ожидание. Если клавиша уже занята, строка покажет «Также занято: ...».

Сочетания с `Ctrl`, `Shift` и `Alt` перехватываются модом и не доходят до игры: например, `Ctrl + Q` с назначенным действием не выбросит стак. Пока вы печатаете в текстовом поле, клавиши мода не срабатывают. Основная клавиша хранится в `options.txt`, модификаторы — в конфиге мода.

### Инструмент (палка)

Инструмент работает в основной руке, когда включён параметр **Инструмент активен**, и не работает в режиме наблюдателя. Предмет меняется в **Настройки → Инструменты → Инструмент**.

Режимы идут по кругу: **Область → Перемещение → Вставка → Заливка → Замена → Удаление**.

| Режим | Левая кнопка | Правая кнопка |
|---|---|---|
| Область | Угол 1 выбранной зоны выделения | Угол 2 |
| Перемещение | Перенести выбранное размещение к цели | Повернуть на 90° |
| Вставка | Запросить вставку, второй клик — подтвердить | Отменить / остановить |
| Заливка | Запросить заливку выделения выбранным блоком, второй клик — подтвердить | Отменить / остановить |
| Замена | Запросить замену одного блока другим в выделении, второй клик — подтвердить | Отменить / остановить |
| Удаление | Запросить удаление выделения, второй клик — подтвердить | Отменить / остановить |

| Ввод с инструментом | Действие |
|---|---|
| `Ctrl` + колесо | Сменить режим |
| Средняя кнопка | Следующий режим; с `Shift` — предыдущий |
| `Alt` + колесо | Сдвинуть зону выделения или размещение на блок по направлению взгляда |
| `Shift` + `Alt` + колесо (области, заливка, замена, удаление) | Сдвинуть только первый угол |
| `Alt` + клик | Взять свою позицию вместо блока под прицелом |
| `Alt` + средняя кнопка (заливка, замена) | Запомнить блок под прицелом: чем заливать / на что менять |
| `Alt` + `Shift` + средняя кнопка (замена) | Запомнить, что заменять (любое состояние этого блока) |

В режиме «Область» угол ставится на сам блок под прицелом. При перемещении начало схемы ставится в соседнюю клетку со стороны грани, по которой вы щёлкнули. Без цели берётся ваша позиция. Инструмент дотягивается до 160 блоков; на дальность лёгкой установки это не влияет.

Без инструмента в руке: правая кнопка по призраку или маркеру сущности — лёгкая установка (если включена), средняя кнопка — пипетка.

### Редактор размещения

Открывается кнопкой **Редактор** во вкладке «Размещения», после **Разместить здесь** или назначенной клавишей. Это прозрачный экран с панелью справа: схема остаётся видна в мире и двигается сразу.

| Ввод | Результат |
|---|---|
| Перетаскивание левой кнопкой вне панели | Двигать схему по горизонтали |
| Щелчок по полю X/Y/Z, число, `Enter` | Задать координату |
| `Ctrl+V` | Вставить три числа из буфера, например `2000 64 -350` |
| Стрелки | Сдвиг по горизонтали на шаг |
| `PgUp` / `PgDn` | Сдвиг вверх / вниз |
| `Shift` + стрелки / `PgUp` / `PgDn` | Сдвиг на 10 шагов |
| Кнопка «Шаг» | Шаг 1, 5, 16 или 64 блока |
| Колесо (обычный вид) | Высота размещения |
| `R` / `M` | Повернуть на 90° / следующее отражение |
| `T` | Вид сверху и обратно |
| Колесо (вид сверху) | Масштаб |
| Перетаскивание правой кнопкой (вид сверху) | Двигать камеру |
| `Enter` или `Esc` | Закрыть редактор |

На панели также есть **Видно**, **Замок**, **Сверху**, **Меню** и **Вставить**. Вид сверху переносит только камеру: рельеф виден лишь в прогруженных чанках.

## Схемы: библиотека файлов

Поддерживаемые форматы:

| Формат | Чтение | Запись |
|---|---|---|
| `.litematic` (Litematica) | Да: несколько регионов, отрицательные размеры, блок-сущности, сущности | Да — основной формат сохранения |
| `.schem` (Sponge v2/v3, WorldEdit, FAWE) | Да | Кнопка **В .schem** |
| `.nbt` (ванильная структура) | Да | Кнопка **В .nbt** |
| `.schematic` (старые MCEdit и Schematica) | Да, числовые ID блоков переводятся в современные | Нет |
| `.bp` (блюпринт Axiom) | Да, без установленного Axiom | Кнопка **В .bp** |

Что есть во вкладке **Схемы**:

- **Фильтр по имени** ищет в текущей папке, подпапки открываются в списке, **На папку выше** возвращает назад.
- Кнопка сортировки переключает: имя, размер (объём схемы), вес файла, дату; повторное нажатие разворачивает порядок.
- Справа — размер, число блоков и регионов, автор, дата, версия данных, размер файла и **3D-превью** из настоящих моделей и текстур. Перетаскивание вращает, правой кнопкой — сдвиг, колесо — масштаб, двойной клик — сброс, с клавиатуры — стрелки и `+`/`-`. Огромные схемы рисуются упрощёнными кубами.
- **Разместить здесь** ставит схему у ваших ног и открывает редактор. Двойной клик по файлу делает то же.
- **В .schem / В .nbt / В .bp** сохраняют копию рядом с файлом (существующий не перезаписывается, добавится `_2`); регионы сводятся в один объём. С установленным Axiom **В .bp** кладёт копию прямо в браузер блюпринтов Axiom.
- **Удалить** удаляет файл с диска, нужно подтвердить вторым нажатием. Восстановить нельзя.
- **Папка** открывает папку в проводнике, **Обновить** перечитывает список.
- Если установлен Axiom, в списке есть папка **Блюпринты Axiom**.

Блоки из старых версий игры проходят через ванильный DataFixer. Неизвестные этой версии блоки пропускаются (не ставятся и не проверяются), а мод пишет в чат, сколько их было.

## Размещения

Вкладка **Размещения** показывает схемы, стоящие в текущем мире и измерении. Список хранится отдельно для каждого сервера (или папки одиночного мира) и измерения.

| Элемент | Что делает |
|---|---|
| Название размещения | Имя в списках; файл не меняется |
| X / Y / Z | Координаты угла. Щелчок по числу — ввод, `Shift` + «±» — шаг 10 |
| Ко мне | Перенести угол туда, где вы стоите |
| Угол: 0/90/180/270 | Поворот на 90° по часовой стрелке |
| Зеркало: нет / Z / X | Отражение |
| Показывать | Выключенное размещение не рисуется и не проверяется |
| Блокировка | Запрет случайно сдвинуть, повернуть, отразить. От вставки мир не защищает |
| Подрегионы (N) | Список подрегионов |
| Сетка | Повтор схемы копиями |
| Редактор | Прозрачный редактор поверх мира |
| Вставить | Поставить схему в мир (творческий режим), со вторым нажатием |
| Перечитать | Перечитать файл с диска, если он изменился |
| Удалить | Убрать размещение (файл остаётся), со вторым нажатием |

Поворот и отражение идут вокруг угла размещения, поэтому X/Y/Z не обязательно совпадают с минимальным углом видимой постройки.

### Подрегионы

Щелчок по подрегиону открывает его страницу: **Показывать подрегион**, сдвиг X/Y/Z, поворот, отражение и **Вернуть на место**. Сдвиг задаётся в осях самой схемы, до поворота размещения, поэтому при повороте размещения подрегион поворачивается вместе со всей постройкой. Сдвинутые подрегионы отмечены звёздочкой. Для общих схем Syncmatica сдвиги приходят с сервера и уходят на сервер.

### Сетка копий

**Сетка** повторяет схему по осям: для каждой оси — сколько копий в минус (`-X`), в плюс (`+X`) и шаг. Шаг **авто** равен размеру схемы по оси, то есть копии стоят вплотную; свой шаг оставляет промежутки или накладывает копии. Все копии — одно размещение: призраки, проверка, процент, материалы, лёгкая установка и вставка считают их вместе. Предел — 256 копий и 268 млн клеток в сумме. **Убрать сетку** оставляет одну копию.

## Слои и границы X/Z

Нажмите **F7** или откройте вкладку **Слои**.

| Режим | Что показывается |
|---|---|
| Все слои | Вся схема |
| Один слой | Только указанная координата |
| Этот и ниже | Координаты не больше указанной |
| Этот и выше | Координаты не меньше указанной |
| Диапазон | От «От» до «До» включительно |

- **Ось** переключает X / Y / Z. Ось Y — горизонтальные этажи, X и Z — вертикальные срезы.
- **К моей позиции** ставит слой на координату ваших ног.
- Клавиши «Слой выше/ниже» сдвигают слой, а если показаны все слои — включают один слой на вашей высоте.

**Границы по X и Z** обрезают схему поверх слоя. **Ограничить по X/Z** включает обрезку, можно ограничить только X, только Z или обе оси.

| Кнопка | Что берёт |
|---|---|
| Здесь | Вашу координату для этой границы |
| По размещению | Границы выбранного размещения |
| По выделению | Границы X/Z и диапазон слоёв по Y из рамки выделения инструмента (если рамок несколько — общую) |
| Сбросить | Снимает ограничение по X/Z, режим слоя остаётся |

Призраки, подсветка ошибок, лёгкая установка, пипетка и Jade работают только внутри слоя и границ. С включённым **Считать только видимую часть** прогресс, счётчики и список материалов тоже считают только эту часть. Вставка тоже ставит только её. Границы сохраняются для каждого мира.

## Лёгкая установка

Правый клик по призраку ставит нужный блок с правильным поворотом и состоянием. Внутри — возможности EasyPlaceFix: мод перебирает направления взгляда и точки клика, моделирует установку и выбирает вариант, который даёт состояние из схемы. Нужный поворот отправляется серверу, а камера остаётся на месте. Включается в **Настройки → Установка → Лёгкая установка** (по умолчанию выключена).

### Когда она срабатывает

- Включены **Показывать схемы** и **Лёгкая установка**; размещение включено и загружено.
- Клетка входит в текущий слой и границы X/Z.
- Вы можете строить (не наблюдатель), не открыт экран, в основной руке нет инструмента.
- Призраки дальше обычной дистанции взаимодействия не ставятся.
- В выживании нужный предмет лежит в основных 36 слотах инвентаря. Предметы в шалкерах сначала достаньте: в «Материалах» и на инфопанели они видны после «+» (`12+52` — 12 под рукой, 52 упаковано).
- У блока есть опора. Призрак, которому сейчас не на чем стоять (снег, факел, ковёр без опоры), пропускается, и луч идёт дальше — к опоре за ним.
- Переименованные предметы и предметы с содержимым не используются, пока не включено **Брать предметы с данными**.

Предмет берётся из хотбара или переносится из инвентаря в текущий слот. В полёте на элитрах лёгкая установка правый клик не перехватывает (фейерверки работают как обычно).

### Темп

| Темп | Пауза между установками |
|---|---|
| Баланс | 2 тика (≈0,1 с) |
| Осторожно | 4 тика — для строгих античитов |
| Быстро | 1 тик |
| Свой | «Своя задержка», 0–20 тиков |

**Случайный лишний тик** добавляет 0 или 1 тик. Это базовая пауза; к ней добавляются ожидание поворота, ответ сервера и повторные клики.

### Поворот и ориентация

- **Поворот для сервера** — сервер получает нужный взгляд, камера не двигается.
- **Упреждение поворота** (0–3 тика) — за сколько тиков до клика отправляется поворот. Для блоков, смотрящих по `FACING`, мод всё равно выдерживает минимум 2 тика.
- **Вернуть взгляд после клика** — сразу после клика отправляет ваш настоящий взгляд.
- **Только точная ориентация** — пропускать блок, если ни один клик не даёт ориентацию из схемы.
- **Клики по скрытым граням и воздуху** — нужны для блоков без опоры; некоторые античиты их отклоняют.

Если сервер отклоняет установки: темп **Осторожно**, выключите клики по воздуху, подойдите ближе, увеличьте упреждение.

### Доведение состояний

С **Доводить состояния** мод после установки делает дополнительные клики: задержка повторителя, режим компаратора, рычаг, открытые люки, двери и калитки, двойные плиты, свечи, слои снега, цветок в горшке, свеча на торте, око в рамке портала, заряд якоря возрождения, высота ноты (для нотных блоков есть очередь кликов и строка прогресса на панели). Текст табличек (лицевая сторона, простой текст) берётся из схемы, у крафтера отключаются нужные слоты.

- **Зажигать и тушить свечи и костры** — огниво или огненный шар зажигают, лопата тушит костёр, пустая рука — свечу.
- **Заливать блоки водой из ведра** (выкл.) — ведро воды заливает, пустое ведро вычерпывает. При промахе вода может пролиться рядом.
- **Наблюдатели ждут** (выкл.) — наблюдатель ставится только после блока, на который смотрит.

Состояние, которое держит мир (например, дверь под сигналом редстоуна), мод изменить не может.

### Сущности схемы

С **Ставить сущности схемы** рамки и светящиеся рамки (с предметом и поворотом), картины и стойки для брони (с бронёй) отмечены маркером. Наведитесь на маркер и нажмите использование. Материалы для сущностей в список материалов не входят.

### Функциональные блоки и контейнеры

С **Открывать контейнеры как обычно** клик по сундуку, печи, верстаку и другому блоку с интерфейсом открывает его, даже если перед ним стоит призрак; `Shift` + клик ставит призрак.

### Защита от лишних блоков

- **Без лишних блоков** (вкл.) — пока включена лёгкая установка, блок из руки нельзя поставить вручную внутри размещения и в 2 блоках от него; удержание кнопки после установки по призраку не ставит второй блок рядом.
- **Защита от ошибок** (выкл.) — то же без лёгкой установки: нельзя поставить вручную блок, которого схема не ждёт.
- В обоих случаях шалкеры, сундуки, эндер-сундуки, бочки, верстаки, печи, наковальни и другие рабочие блоки можно ставить туда, где в схеме воздух.

### Ломание

- **Защита при раскопках** (выкл.) — пока включена лёгкая установка, не даёт ломать: **вне схемы** (блоки за пределами показанных схем; функциональные блоки ломать можно) и **верные блоки** (уже совпадающие со схемой). **Пояснять** — причина над хотбаром.
- **Не портить блоки схемы инструментами** (вкл.) — отменяет ПКМ лопатой, мотыгой или топором, если блок превратился бы в то, чего нет в схеме (дёрн в тропинку, землю в грядку, бревно в обтёсанное).
- **Автосмена инструмента** (выкл.) — перед ломанием блока внутри включённого размещения берёт лучший инструмент. Работает и без лёгкой установки.
- **Ломать неверные блоки** (выкл.) — другой блок или нужный блок не той стороной выкапывается и ставится заново, по одному блоку за раз. Не трогаются контейнеры, рабочие блоки, эндер-сундуки, кафедры, проигрыватели, маяки, спавнеры, жидкости и неразрушаемые блоки. Лишние блоки там, где схема ждёт воздух, убирайте сами.
- **Замена вариантов земли** (выкл.) — земля, дёрн, грубая земля и тропинка на месте другого варианта выкапываются и заменяются (землю и дёрн друг на друга не меняет, если они взаимозаменяемы).

### Предметы

- **Защита слотов** — отметьте слоты хотбара 1–9 (щелчком или клавишами 1–9). Лёгкая установка, пипетка и автосмена инструмента только выбирают их, но ничего в них не кладут — инструменты остаются на местах. Закреплённые в Inventory Profiles Next слоты тоже учитываются.
- **Замена материалов** (выкл.) — если нужного блока нет, ставится другая калитка, люк или коралловый веер того же вида либо блок из вашего списка замен. **Добавить из руки** добавляет блок из основной руки в список (до 256), **Очистить список** — очищает. Стены другими стенами не подменяются. Сверка по-прежнему сравнивает с исходной схемой, поэтому заменённый блок может показываться ошибкой — для постоянной замены используйте вкладку [Замены](#замены-блоков).
- **Объяснять отказы** (вкл.) — над хотбаром видно, почему блок не поставлен (нет предмета, предмет только с данными, нужно повернуться и т. д.).

## Версия с принтером

Файл `litematica-plus-lts-1.0.5-printer.jar` — тот же мод с тем же id плюс принтер. Принтер сам ставит недостающие блоки схемы вокруг вас, без кликов, и берёт настройки лёгкой установки: темп, поворот для сервера, доведение состояний, ломание неверных блоков, замены, слои и границы.

- Включается в **Настройки → Принтер → Принтер** или клавишей «Вкл/выкл принтер» (по умолчанию не назначена).
- **Дальность принтера** — 1–6 блоков от глаз, по умолчанию 4; дальше обычной дистанции игры принтер не дотягивается.
- Настройки принтера сохраняются сразу в `config/litematicaplus-printer.json`.

Перед использованием на сервере убедитесь, что принтеры там разрешены.

## Материалы

Выберите размещение и откройте **Материалы**.

| Столбец | Значение |
|---|---|
| Предмет | Предмет (стаки показаны как `130 (2 ст + 2)`) |
| Всего | Сколько нужно на весь объём (или на видимую часть) |
| Нужно | Сколько ещё не поставлено правильно |
| Есть | Сколько у вас; после «+» — упаковано в шалкеры или лежит в эндер-сундуке |

Подсчёт понимает двойные плиты, свечи, слои снега, огурцы, вёдра жидкостей; цветок в горшке — это горшок и цветок, торт со свечой — торт и свеча; верхние половины дверей и изголовья кроватей не удваиваются. Блок, который стоит, но повёрнут или в другом состоянии, материала не требует (кроме плит, свечей и слоёв, где состояние — это количество).

- **Сортировка**: не хватает, всего, название, нет в инвентаре.
- **Скрыть готовые** — не показывать материалы, которых уже хватает.
- **Скрыть призраки** — скрыть в мире призраки выбранного материала во всех схемах (сверка и счётчики не меняются); повторное нажатие возвращает. То же делают клавиши «Скрыть призрак блока под прицелом» и «Показать все скрытые блоки». Выбор запоминается для каждого мира и сервера.
- **Щелчок по строке** подсвечивает сквозь стены запомненные контейнеры, где лежит этот материал (нужно **Запоминать открытые контейнеры**).
- **Экспорт**: Excel `.xlsx` (листы «Сводка», «Собрать», «Все материалы»), CSV, Markdown, JSON или **Буфер**. Файлы — в `litematica-plus/materials/`, в чате появится ссылка на файл и папку. Буфер копирует видимые строки, файлы — весь список.

**Эндер-сундук** прибавляется к «Есть», если после входа вы его один раз открыли (**Учитывать эндер-сундук в материалах**).

**Память контейнеров**: мод запоминает содержимое сундуков, бочек и шалкеров, которые вы открывали в этом мире за текущий заход. Запомненные контейнеры в пределах 64 блоков, где лежит материал, которого не хватает в инвентаре, обводятся оранжевым сами (**Подсвечивать контейнеры с нужными материалами**).

### Помощник у контейнеров

Откройте сундук, бочку, шалкер, эндер-сундук, вагонетку или лодку с сундуком, раздатчик, воронку, осла, мула или ламу:

| Подсветка | Значение |
|---|---|
| Зелёная | Нужный предмет россыпью |
| Жёлтая | Шалкер с нужными предметами внутри |
| Голубая | Слоты предмета из строки под курсором |

Сбоку — **панель материалов**: чего не хватает, сколько этого здесь и сколько у вас.

- Клик по строке — взять нужное количество этого предмета; `Shift` + клик — взять отсюда всё такое; правый клик — передать количество в Stack Calculator.
- **Взять нужное** (или клавиша «Взять материалы из открытого контейнера») — забрать ровно недостающее. Стак при необходимости делится несколькими кликами, шалкер берётся целиком, только если россыпью не хватает.
- **Сложить лишнее** — вернуть материалы сверх нужного. Предмет в руке и слоты, закреплённые в IPN, не трогаются.
- Кнопка «−/+» в заголовке сворачивает панель до одной строки; подсветка слотов остаётся, итог переноса пишется над хотбаром.

Перед переносом положите предмет с курсора. Закрытие контейнера останавливает перенос.

В подсказке предмета видно, сколько его ещё нужно, а в подсказке шалкера — какие нужные предметы внутри (**Нужды схемы в подсказках предметов**, работает вместе с ShulkerBoxTooltip).

Пока схемы скрыты или выбранное размещение выключено, схема молчит: нет инфопанели, помощника у контейнеров и строк в подсказках (**Скрытая схема о себе не сообщает**).

## Замены блоков

Во вкладке **Замены** любой блок схемы, кроме блоков с содержимым (сундуки, таблички), можно заменить другим для выбранного размещения:

1. Слева выберите блок схемы.
2. Справа выберите, из чего строить вместо него; похожие блоки идут первыми, есть **Поиск блока** по названию или id.
3. **Оставить исходный блок** отменяет замену, **Сбросить все** — все замены размещения.

Призраки, сверка, материалы, лёгкая установка и вставка сразу видят замену. Файл не меняется, замены хранятся у размещения. **Применять замены блоков** в настройках выключает их, не удаляя.

## Проверка постройки

Мод сравнивает каждую секцию схемы с миром при любом изменении блока или загрузке чанка, в фоновых потоках.

| Категория | Цвет по умолчанию | Значение |
|---|---|---|
| Нет блока | Голубой `2FC7FF` | Схема требует блок, в мире воздух |
| Лишний | Розовый `FF4FD8` | Схема ждёт воздух, в мире блок |
| Не тот блок | Красный `FF4444` | Другой тип блока |
| Не то состояние | Оранжевый `FFA62B` | Блок тот же, отличается поворот или свойство |

Цвета меняются в **Настройки → Вид → Подсветка ошибок** (образцы, стрелки, поле `RRGGBB`, **Вернуть цвета по умолчанию**). Подсветка рисуется только на открытых гранях (не закрытых соседним блоком, водой, льдом, стеклом) и только в прогруженных чанках.

Вкладка **Проверка** показывает до 200 ближайших ошибок. Переключатели категорий управляют показом. Щелчок по строке рамкой выделяет место в мире, **Снять подсветку** убирает рамку. Строка внизу говорит, сколько блоков в непрогруженных чанках не проверено.

Правила сверки (**Настройки → Сверка**):

- **Игнорировать изменчивые свойства** (вкл.) — не ошибка: заряд редстоуна, возраст растений, дистанция листвы, горящая печь, нажатая кнопка, выдвинутый поршень. Поворот, задержка повторителя, режим компаратора, нота, рычаг, открытые двери, зажжённые свечи и костры сравниваются строго.
- **Засчитывать похожие блоки** (выкл.) — принимается блок того же вида: камень вместо кварца, обычное стекло вместо крашеного, любые ступени с тем же поворотом. Редстоун, рельсы, сыпучие блоки, стены и блоки с содержимым — строго.
- **Земля и дёрн взаимозаменяемы** (вкл.).
- **Скрытые блоки считать верными** (вкл.) — на сервере «не тот блок», закрытый с шести сторон, ошибкой не считается: антирентген подменяет такие блоки. В одиночной игре не действует.
- **Сверять непрогруженное по Voxy** (вкл.) — с Voxy и VoxyMap непрогруженные части сверяются по блокам, сохранённым Voxy. Результат сверки секции запоминается и после выгрузки чанка, поэтому процент не прыгает от того, куда вы летите.

**100 % готовности** — это доля верных непустых блоков. Лишние блоки в воздухе, содержимое контейнеров и сущности проверяйте отдельно. Для финальной проверки: все слои, без границ, все категории включены.

## Новая схема: сохранить постройку

1. Возьмите палку, режим **Область** (`Ctrl` + колесо).
2. Левой кнопкой — первый угол, правой — второй. Обе крайние клетки входят в выделение.
3. **H → Новая схема**: углы можно поправить числами, **Здесь** ставит угол на вашу позицию.
4. Для постройки сложной формы нажмите **Новая зона** и выделите следующую часть. Каждая зона станет подрегионом схемы, её название — именем подрегиона.
5. Впишите **Имя файла** и нажмите **Сохранить**. Если файл есть, кнопка станет **Заменить**.

Подробности:

- Файл сохраняется как `.litematic` в корень папки схем. Автор — из настройки **Автор**, если пусто — ваш ник.
- Предел — 268 435 456 клеток в сумме (предел формата `.litematic`), воздух и пересечения зон считаются. Мод заранее проверяет память и, если её мало, предлагает выделить игре больше или разбить область.
- Вкладка предупреждает о непрогруженных чанках: они сохранятся пустыми. С Voxy и VoxyMap такие чанки берутся из Voxy — только блоки, без содержимого сундуков, табличек и сущностей. После сохранения мод скажет, сколько чанков пропущено или взято из Voxy.
- В одиночной игре сохраняются полные данные блок-сущностей и сущности. На сервере — то, что знает клиент; стойки, рамки и другие сущности попадают в схему и там.
- На сервере секции копируются порциями по 5 мс, поэтому большая область сохраняется без зависания.
- С Axiom: **Взять выделение** добавляет зону по выделению Axiom, **Выделить в Axiom** отдаёт зоны в Axiom, **Буфер Axiom** сохраняет скопированное в Axiom в `.litematic` с содержимым контейнеров и сущностями.

## Вставка, заливка, замена и удаление

Все четыре действия меняют реальные блоки и требуют **творческого режима**. Собственной отмены у мода нет: остановка прекращает операцию, но не возвращает изменённое. Перед большой операцией сделайте копию мира.

Каждое действие запрашивается первым кликом и выполняется вторым (подтверждение действует около 4 секунд). Правая кнопка с инструментом отменяет и останавливает.

### Вставка

Кнопка **Вставить** во вкладке «Размещения» или в редакторе, либо инструмент в режиме **Вставка**.

| Режим «Вставка» в настройках | Что делается |
|---|---|
| заменять всё | Мир приводится к схеме, включая воздух схемы |
| не стирать воздухом | Ставятся только непустые блоки, воздух схемы мир не трогает |
| только в воздух | Блоки ставятся только в пустые клетки |

- Вставляется только то, что внутри текущего слоя и границ X/Z (слой фиксируется при запуске). Чтобы вставить всё — режим «Все слои» и без границ.
- Учитываются подрегионы, сетка и замены. Непрогруженные секции пропускаются.
- **В одиночной игре** вставка идёт напрямую: переносится содержимое сундуков и табличек (**Вставлять содержимое**), а после блоков ставятся сущности схемы с поворотом и отражением (**Вставлять сущности**); повторная вставка дубликатов не плодит. Итог появляется после последней порции.
- **На сервере** — командами `/setblock` и `/fill ... strict`, по умолчанию 8 команд за тик (**Команд вставки за тик**, 1–16). Без прав оператора — примерно одна команда в секунду, чтобы не кикнуло за спам. Содержимое контейнеров и сущности командами не вставляются. Итог «отправлены команды» — не подтверждение сервера, результат смотрите в мире.
- С Axiom кнопка **Вставить через Axiom** передаёт размещение во вставку Axiom ровно на своё место (с поворотом, подрегионами, сеткой, заменами, слоем и границами). Двигайте гизмо и подтверждайте в Axiom, отмена — историей Axiom.

### Заливка, замена и удаление

Работают по **всем полностью заданным зонам выделения** (а не по размещению), предел — 64 млн блоков.

- **Заливка**: наведитесь на блок в мире и нажмите `Alt` + среднюю кнопку — он станет блоком заливки (с точным состоянием).
- **Замена**: `Alt` + средняя кнопка — на что менять, `Alt` + `Shift` + средняя кнопка — что заменять (любое состояние). Выбранные блоки видны на инфопанели.
- **Удаление** заполняет зоны воздухом.

На сервере используются `/fill ... strict` и `/fill ... replace`.

## Зоны для командной стройки

Вкладка **Зоны** делит выбранное размещение на участки, чтобы строить вместе и не мешать друг другу.

1. Справа задайте **По X**, **По Z** и **Этажи** (до 16 частей по каждой оси). Размер берётся по рамке всего размещения, включая сетку.
2. Выберите зону и нажмите **Взять себе**. **Только эта зона** показывает только её (это обычные слой и границы X/Z), так что призраки, лёгкая установка и материалы касаются только вашей зоны. **Показать всё** возвращает полный вид, **Освободить** отдаёт зону.
3. У каждой зоны виден процент готовности по реальным блокам мира — работа товарищей видна без всякой связи. На инфопанели появляется «Ваша зона N: процент».

**Связь с командой.** В блоке **Команда** впишите ники товарищей через запятую и выберите способ связи:

| Способ | Куда уходит |
|---|---|
| Личные сообщения (`/msg`) | Каждому товарищу из списка отдельно |
| Командный чат (`/teammsg`) | Один раз, всей вашей ванильной команде (`/team`) |
| Своя команда | Шаблон, например `clan chat {text}` или `w {player} {text}`; с `{player}` — каждому товарищу |

Мод **никогда не пишет в общий чат**. Команды, которые пишут всем (`say`, `me`, `tellraw`, `broadcast` и подобные), запрещены; если выбранной команды нет на сервере, мод ничего не отправит и скажет об этом. Команды уходят не чаще раза в 1,25 с. У товарищей с модом служебные строки `[LP-zones ...]` скрыты (**Скрывать служебные сообщения зон**), сообщения от игроков не из списка не применяются.

**Отправить план** рассылает разбивку: у товарища она применится, если у него та же схема на том же месте (например, общая через Syncmatica). **Кто что взял?** просит товарищей повторить свои зоны — удобно после входа. Если двое возьмут одну зону одновременно, остаётся последнее сообщение.

## Общие схемы сервера (Syncmatica)

Если на сервере стоит плагин Syncmatica (Paper, Purpur, Folia) или мод Syncmatica (сервер Fabric), мод подключается к нему сам при входе, а в чате появляется сообщение, сколько общих схем на сервере.

Во вкладке **Сервер**:

- **Загрузить** (или двойной клик) — скачать общую схему и показать у себя; **Убрать у себя** — скрыть у себя, на сервере она останется.
- **Поделиться «...»** — отправить выбранное размещение на сервер.
- **Удалить с сервера** — удалить у всех, со вторым нажатием.
- Чтобы сдвинуть общую схему для всех, снимите **Блокировку** во вкладке «Размещения» (сервер даёт правку одному игроку за раз), подвиньте и заблокируйте снова — новое положение уйдёт всем.

Скачанные файлы лежат в `schematics/syncmatics/` и сверяются по хешу. Если установлен отдельный мод Syncmatica, вкладка выключена — общими схемами занимается он. Выключить связь: **Настройки → Инструменты → Общие схемы сервера (Syncmatica)**.

## Аддоны и совместимость

Вкладка **Аддоны** показывает каждую интеграцию: «Работает», «Ждёт», «Выключено», «Не установлен», «Ошибка» или «Конфликт», её настройки и журнал проблем. **Скопировать отчёт** копирует сведения о модах и ошибках для баг-репорта.

| Мод | Что даёт |
|---|---|

| Voxy | С шейдерами мод добавляет глубину дальнего рельефа Voxy, и схема не просвечивает сквозь дальние горы |
| VoxyMap | Размещения на 3D-карте (рамка с названием и процентом), в панели объектов и на миникарте; сверка и сохранение непрогруженных чанков по данным Voxy. Слой «Схемы (Litematica Plus)» в настройках VoxyMap выключает показ |
| Jade | Подсказка показывает блок схемы под прицелом: поставлен ли, совпадает ли, какое состояние ждёт |
| Stack Calculator | Правый клик по строке панели материалов передаёт количество в калькулятор |
| Inventory Profiles Next | Закреплённые слоты не трогают помощник материалов, лёгкая установка и автосмена инструмента |
| Mod Menu | Кнопка настроек в списке модов |
| Axiom | Блюпринты `.bp`, вставка через Axiom, обмен выделениями, сохранение буфера Axiom. Пока открыт редактор Axiom, мод не перехватывает клики и клавиши (**Уступать редактору Axiom**) |
| Syncmatica (сервер) | Общие схемы, см. выше |
| Litematica | Конфликт: оставьте только один из модов |

Проверено автотестом в игре: без модов рендера и с Sodium 0.9.3-alpha.1 + Iris 1.11.6 + Complementary Reimagined r5.9.3; панель материалов — с Inventory Profiles Next 2.3.8, Stack Calculator 1.2.0 и Jade 26.3.3. На настоящем сервере с античитом мод автотестом не проверялся.

## Файлы и восстановление

Все пути — внутри папки **текущего игрового профиля**.

| Путь | Что хранится |
|---|---|
| `config/litematicaplus.json` (+ `.bak`) | Основные настройки |
| `config/litematica-plus-session.json` (+ `.bak`) | Размещения, выделения, слои, границы, замены, скрытые призраки, режим инструмента — по серверу или миру и измерению |
| `config/litematica-plus-substitutes.json` (+ `.bak`) | Список замены материалов |
| `config/litematicaplus-printer.json` | Настройки принтера |
| `config/litematicaplus/previews/` | Кэш превью (можно удалить) |
| `schematics/` | Схемы |
| `schematics/syncmatics/` | Скачанные общие схемы сервера |
| `litematica-plus/materials/` | Экспорт материалов |
| `options.txt` | Основные клавиши мода |

- Файлы пишутся атомарно: временный файл, замена, резервная копия `.bak`. Если основной файл повреждён, мод читает `.bak`.
- Файл сессии от более новой версии мода открывается только для чтения.
- После повторного входа режимы инструмента, меняющие мир (вставка, заливка, замена, удаление), сбрасываются на «Область».
- Схемы в файл сессии не встроены: если файл схемы переместить или удалить, размещение не загрузится.
- Перезапись `.litematic` при сохранении не делает копию старой схемы — сохраняйте её сами.

Ручное редактирование конфига: закройте игру, сделайте копию файла и `.bak`, поправьте JSON (пути в Windows удобно писать через `/`), запустите игру. Для полного сброса настроек переименуйте **и** `litematicaplus.json`, **и** `litematicaplus.json.bak`, иначе мод восстановит копию.

## Решение проблем

| Проблема | Что проверить |
|---|---|
| `H` не открывает меню | Мод в папке именно этого профиля; клавиша в «Управлении»; конфликт клавиш. Откройте через Mod Menu. Старые профили могли сохранить прежнюю клавишу `K` — переназначьте |
| Предупреждение о Litematica | Оставьте в `mods` только один мод |
| Файла нет в списке | Нужная папка профиля, поддерживаемое расширение, текущая подпапка, пустой фильтр, **Обновить** |
| Ошибка загрузки схемы | Сообщение во вкладке «Размещения» и `logs/latest.log`; файл может быть повреждён |
| Схема загружена, но не видна | «Показывать схемы», «Показывать» у размещения, координаты и измерение, слой и границы, дальность отрисовки, скрытые призраки |
| Дальняя часть не видна | Чанки не прогружены: включено «Призраки только в прогруженных чанках» |
| Призраки просвечивают сквозь дальние горы | Включите «Призраки только в прогруженных чанках»; посмотрите вкладку «Аддоны» → Voxy |
| ПКМ ставит угол выделения | В руке палка-инструмент: смените предмет или выключите инструмент |
| ПКМ ничего не строит | Лёгкая установка и показ схем вкл.; меню закрыто; вы близко; слой; предмет в инвентаре; опора. Включите «Объяснять отказы» |
| «В инвентаре нет», хотя предмет есть | Он в шалкере, во второй руке или с данными (имя, содержимое) |
| Сундук открывается вместо установки | Это «Открывать контейнеры как обычно»: `Shift` + клик |
| Нельзя поставить блок вручную рядом со схемой | «Без лишних блоков» (2 блока вокруг) или «Защита от ошибок» |
| Нельзя ломать | «Защита при раскопках» и её правила |
| Блок встаёт не той стороной | «Поворот для сервера», упреждение 2–3, «Только точная ориентация», есть ли опора |
| Нет панели у сундука | Выбрано размещение, помощник и панель вкл., схема не скрыта; переоткройте контейнер |
| Перенос остановился | Предмет на курсоре, полный инвентарь или контейнер |
| Материалы и процент меняются при смене слоя | Включено «Считать только видимую часть» |
| 100 %, но ошибки есть | Процент — по непустым блокам; лишние блоки, сущности и содержимое — отдельно |
| Вставилась только часть | Задан слой или границы X/Z |
| Вставка не работает | Творческий режим; на сервере — права на `/setblock` и `/fill`; чанки прогружены; нет другой операции |
| Сохранённая схема с дырами | Часть чанков не была прогружена; пролетите над ними или установите Voxy + VoxyMap |
| Вкладка «Сервер» выключена | Стоит отдельный мод Syncmatica или на сервере нет Syncmatica |
| Схема пропала после ошибки рендера | В логе `Schematic rendering failed`; перезапустите игру, проверьте сочетание модов и шейдеров |
| Размещения не восстановились после входа | Тот же адрес сервера или папка мира и измерение; файл схемы на месте; сессия не в режиме «только чтение» |

Если проблема в интеграции — откройте **Аддоны**, нажмите **Скопировать отчёт** и приложите его к сообщению об ошибке.

## Ограничения

- На сервере не вставляются сущности и содержимое контейнеров (предел длины команды). Рамки, картины и стойки в выживании ставятся лёгкой установкой.
- Проекты схем Litematica не поддерживаются.
- С шейдерами Iris призраки рисуются поверх готового кадра: тени, блум и тональная коррекция пакета на них не действуют; сундуки и другие спецблоки рисуются непрозрачными.
- В виде сверху рельеф виден только в прогруженных чанках; в некоторых шейдерпаках он может тонуть в дымке.
- Материалы для сущностей в список не входят.
- Лёгкая установка переносит только лицевой текст табличек без форматирования и не заполняет сундуки.
